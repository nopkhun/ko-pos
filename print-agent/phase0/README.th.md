# ทดสอบเครื่องพิมพ์ EASY PRINT ES-8803WA (Phase 0)

เอกสารนี้ช่วยให้คุณหา IP ของเครื่องพิมพ์ ทดสอบว่าคอมพิวเตอร์เชื่อมต่อกับเครื่องพิมพ์ได้
และสั่งพิมพ์ทดสอบ **ก่อน** ที่จะติดตั้งระบบ KO Print Agent ตัวเต็ม

ไม่ต้องมีความรู้ด้านโปรแกรมมิ่ง ทำตามขั้นตอนด้านล่างได้เลย

---

## ขั้นตอนที่ 1: หา IP ของเครื่องพิมพ์

เครื่องพิมพ์ต้องต่อ WiFi **วงเดียวกัน** กับคอมพิวเตอร์ที่รันโปรแกรม (ร้านค้าเดียวกัน,
เราเตอร์ตัวเดียวกัน) ไม่เช่นนั้นจะเชื่อมต่อกันไม่ได้

### วิธีที่ 1: พิมพ์หน้า Self-Test ของเครื่องพิมพ์

1. ปิดเครื่องพิมพ์ก่อน (ถอดปลั๊ก หรือกดปุ่ม Power ให้ดับ)
2. กดปุ่ม **FEED** ค้างไว้ แล้วเปิดเครื่อง (เสียบปลั๊ก/กด Power) โดยยังกดปุ่ม FEED ค้างต่อไป
3. ปล่อยปุ่มหลังจากได้ยินเสียง "ติ๊ด" หรือเครื่องเริ่มพิมพ์กระดาษออกมาเอง
4. เครื่องจะพิมพ์หน้า "Self-Test" ออกมา ซึ่งจะมีข้อมูล เช่น รุ่นเครื่อง, เวอร์ชัน
   Firmware, และ **IP Address** ของเครื่อง (มองหาแถวที่เขียนว่า `IP Address`
   หรือ `IP:`) — จดตัวเลขนี้ไว้ เช่น `192.168.1.50`

> หมายเหตุ: ขั้นตอนกดปุ่มอาจแตกต่างกันเล็กน้อยตามรุ่น/Firmware ถ้าทำตามนี้แล้วไม่ได้
> ให้ลองค้นหาคู่มือ "ES-8803WA self test" หรือสอบถามร้านที่ขายเครื่องพิมพ์

### วิธีที่ 2: ใช้โปรแกรมตั้งค่า WiFi ของเครื่องพิมพ์ (ถ้ามี)

เครื่องพิมพ์บางรุ่นมาพร้อมโปรแกรม/แอปสำหรับตั้งค่า WiFi (มักมาในแผ่น CD หรือดาวน์โหลด
จากเว็บผู้ผลิต) ซึ่งจะโชว์ IP ของเครื่องพิมพ์ให้เห็นตรงๆ และช่วยให้คุณตั้งค่าเชื่อมต่อ
WiFi ของเครื่องพิมพ์ให้ตรงกับ WiFi ของร้านได้ด้วย ถ้าเครื่องพิมพ์ยังไม่เคยต่อ WiFi ของร้าน
มาก่อน ให้ใช้โปรแกรมนี้ตั้งค่าก่อน แล้วค่อยพิมพ์ Self-Test ตามวิธีที่ 1 อีกครั้งเพื่อยืนยัน IP

### สำคัญ: ตั้ง IP แบบคงที่ (Static IP / DHCP Reservation)

โดยปกติเราเตอร์จะแจก IP ให้เครื่องพิมพ์แบบสุ่ม (DHCP) ซึ่ง **IP อาจเปลี่ยนได้** เวลา
เครื่องพิมพ์ถูกปิด-เปิดใหม่ หรือเราเตอร์รีสตาร์ท ถ้า IP เปลี่ยน โปรแกรมพิมพ์จะหาเครื่องพิมพ์
ไม่เจอทันที

**แนะนำอย่างยิ่ง** ให้ตั้งค่า **DHCP Reservation** (จองไอพีให้อุปกรณ์ตาม MAC Address)
ที่หน้าตั้งค่าเราเตอร์ของร้าน เพื่อให้เครื่องพิมพ์ได้ IP เดิมทุกครั้ง — ถ้าไม่ทราบวิธี
ให้สอบถามช่างที่ติดตั้งเราเตอร์ หรือสอบถามทีมงาน KO POS

## ขั้นตอนที่ 2: ตรวจสอบว่าคอมพิวเตอร์เชื่อมต่อเครื่องพิมพ์ได้ (PowerShell)

1. เปิด **PowerShell** บน Windows (กดปุ่ม Start พิมพ์ว่า `PowerShell` แล้วกด Enter)
2. พิมพ์คำสั่งนี้ (แทนที่ `192.168.1.50` ด้วย IP ที่จดไว้จากขั้นตอนที่ 1):

   ```powershell
   Test-NetConnection 192.168.1.50 -Port 9100
   ```

3. ดูผลลัพธ์ที่บรรทัด `TcpTestSucceeded`:
   - `TcpTestSucceeded : True` → เชื่อมต่อได้ ไปขั้นตอนที่ 3 ได้เลย
   - `TcpTestSucceeded : False` → เชื่อมต่อไม่ได้ ให้ตรวจสอบ:
     - เครื่องพิมพ์เปิดอยู่หรือไม่ / มีไฟสถานะ WiFi ติดหรือไม่
     - IP ที่ใช้ถูกต้องหรือไม่ (ลองพิมพ์ Self-Test ใหม่)
     - คอมพิวเตอร์กับเครื่องพิมพ์ต่อ WiFi วงเดียวกันหรือไม่ (ชื่อ WiFi เดียวกัน)
     - Windows Firewall (ปกติไม่ค่อยบล็อกการเชื่อมต่อ "ขาออก" แบบนี้ แต่ถ้าลองแล้ว
       ยังไม่ได้ ให้ลองปิด Firewall ชั่วคราวเพื่อทดสอบ)

## ขั้นตอนที่ 3: สั่งพิมพ์ทดสอบ

มี 2 วิธีให้เลือก ทำวิธีไหนก็ได้ (แนะนำวิธี A ถ้ายังไม่ได้ลง Python)

### วิธี A: ใช้ PowerShell (ไม่ต้องลง Python)

1. เปิด PowerShell ในโฟลเดอร์นี้ (โฟลเดอร์ที่มีไฟล์ `test_print.ps1`)
   - วิธีเร็วที่สุด: เปิด File Explorer ไปที่โฟลเดอร์นี้ กด `Shift + คลิกขวา`
     ที่พื้นที่ว่าง แล้วเลือก "Open PowerShell window here"
2. หากเป็นครั้งแรกที่รันสคริปต์ PowerShell บนเครื่องนี้ อาจต้องอนุญาตก่อนด้วยคำสั่ง:

   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```

   (คำสั่งนี้อนุญาตเฉพาะหน้าต่างปัจจุบัน ไม่กระทบเครื่องถาวร)

3. รันคำสั่ง (แทน IP ด้วยของจริง):

   ```powershell
   .\test_print.ps1 192.168.1.50
   ```

4. ดูข้อความผลลัพธ์: ถ้าขึ้น `[OK] ...สำเร็จ` และกระดาษพิมพ์ออกมาข้อความ
   "KO POS TEST OK" พร้อมตัดกระดาษ แสดงว่าใช้งานได้แล้ว

### วิธี B: ใช้ Python (ถ้าติดตั้ง Python ไว้แล้ว)

1. เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์นี้
2. รันคำสั่ง:

   ```
   python test_print.py 192.168.1.50
   ```

3. ผลลัพธ์จะแสดงข้อความภาษาไทย/อังกฤษบอกว่าสำเร็จหรือผิดพลาดตรงไหน

## ถ้าพิมพ์ไม่ออก / มีปัญหา

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| `Test-NetConnection` ขึ้น False | IP ผิด, เครื่องพิมพ์ปิดอยู่, คนละ WiFi | พิมพ์ Self-Test ใหม่เพื่อดู IP, ตรวจสอบไฟเลี้ยง/WiFi |
| เชื่อมต่อได้ (`True`) แต่พิมพ์ไม่ออก | ไม่มีกระดาษ, ฝาเครื่องพิมพ์เปิดอยู่ | ใส่กระดาษให้ถูกทิศทาง, ปิดฝาให้สนิท |
| พิมพ์ออกแต่ตัดกระดาษไม่ทำงาน | เครื่องพิมพ์บางรุ่นใช้คำสั่งตัดกระดาษคนละแบบ | แจ้งทีมงาน KO POS เพื่อปรับคำสั่งตัดกระดาษ |
| IP เปลี่ยนไปทุกครั้งที่เปิดเครื่อง | เราเตอร์แจก IP แบบสุ่ม (DHCP) | ตั้งค่า DHCP Reservation ตามขั้นตอนที่ 1 |

เมื่อทดสอบผ่านขั้นตอนนี้แล้ว ถือว่า "เครื่องพิมพ์พร้อมใช้งาน" และสามารถไปติดตั้ง
โปรแกรม KO Print Agent ตัวเต็มต่อได้ (ดู `README.th.md` ที่โฟลเดอร์หลักของ print-agent)
